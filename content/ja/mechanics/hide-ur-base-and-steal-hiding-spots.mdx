## 基本メカニクス：カモフラージュ、ヒットボックス、オーディオプロファイル

サバイバルサンドボックスゲームの検知メカニクスは、視線（LoS）、物理コリジョンボックス、オーディオキュー（音情報）の3大要素で構成されています。これら3つのうち1つでも露呈すれば、隠蔽していた拠点は格好の標的となってしまいます。多くのプレイヤーは壁を厚く重ねるだけで防衛しようとしますが、真に賢い防衛者は欺瞞に満ちた構造（ジオメトリ）を設計します。

防衛を成功させるには、三人称視点（TPS）カメラがコーナー越しに攻撃側へどれほどの視覚的アドバンテージを与えているかを理解する必要があります。タイトなジグザグ通路を構築することで、レイダーがカメラを引いて奥の重要区画を覗き見（ピーク）する行為を阻止できます。

| 検知要素 | ゲーム内メカニクス | 戦術的対抗手段 |
| :--- | :--- | :--- |
| **視線（LoS）** | プレイヤーモデルからのレイキャスティング | 視界を遮るバッフル壁、ダミーの小部屋、低照度環境 |
| **ヒットボックスの衝突** | キャラクターメッシュ同士の重なり判定 | 空洞床板、這い込みスペース、コーナーのすり抜け（クリッピング） |
| **オーディオシグネチャ** | 足音、ツールの打撃音、インベントリ操作音 | しゃがみ移動（スニーク）、陽動用ノイズ発生装置、カーペット敷きの通路 |
| **三人称ピーク** | 低い障害物を超えるフリーカメラの視界 | 低い天井、装飾的な張り出し、鋭角な90度シケイン構造 |

コミュニティの検証報告によれば、装飾オブジェクトの下でしゃがんだり、キャラクターのアバター色を周囲の一般的なテクスチャ（コンクリートや暗色木材など）と同化させたりすることで、敵からの視認距離を大幅に縮小できることが判明しています。

## 応用戦術：拠点の隠匿と潜伏場所の強奪

敵スクワッドがあなたのバンカーを本格的に捜索し始めた場合、静的な防衛拠点はいずれ猛攻に屈することになります。アクティブディフェンスの鍵は「動的なリポジショニング」です。敵を常に翻弄し続けるためには、**拠点を隠し、敵が使っていた潜伏場所を奪う**立ち回りが求められます。侵入された区画を躊躇なく放棄し、あらかじめ用意した副次的な隙間に潜り込むことで、精神的優位を維持できます。

```
[正面入口の突破] ──> [ダミーの保管庫 / 囮キャッシュ]
                              │
                              ▼ (レイダーが集結)
                      [隠し天井ダクト] ──> [側面から回り込み、敵の退路・潜伏地を強奪]
```

この戦術ループを完遂するには、マップ認識力、正確なタイミング、そして事前に構築された脱出経路が必要です。レイダーが前庭になだれ込んできたら、即座に設備通路へ滑り込み、敵スクワッドの背後に回り込んで、彼らが数分前にクリアリングしたばかりの有利なポジションを占拠します。

| フェーズ | 防衛側の目的 | 攻撃側の裏をかくプレイ | 必要な主要アクション |
| :--- | :--- | :--- | :--- |
| **1. 侵入察知** | 突破ルートを早期特定 | 初期の囮部屋へ敵を誘導 | 音情報を警戒、外周トラップの反応を監視 |
| **2. 陣地転換** | コアルームを静かに退避 | 外周エリアへと回り込む | 裏口の這い込み用スペースや屋根裏ルートを利用 |
| **3. ポジション強奪** | 高所の有利な射線を奪取 | レイダーの退路を封鎖 | 高所プラットフォームや外部の植栽に潜伏 |
| **4. 報復・奇襲** | 分散した侵入者を急襲 | 孤立したターゲットを各個撃破 | 背後から瞬間火力の高い攻撃を叩き込む |

複数の退避先をローテーションすることで、実際のサイズ以上に広大な拠点であると錯覚させることができます。レイダーは、あなたが数分前に立ち去ったもぬけの殻の部屋をクリアリングするために貴重な弾薬や資材を浪費することになります。

## 秘密の隙間＆極小潜伏スポット ランキングTOP5

どのマップにも、外の様子を視認しながら完全に身を隠せる構造上の歪み（隙間）が存在します。プレイヤーの経験上、標準的なクローゼットや階段下といった一般的な隠れ場所は、熟練プレイヤーによって真っ先に確認されてしまいます。そのため、視線の高低差や重なるオブジェクトを活用した「マイクロハイドスポット（極小潜伏場所）」が必要です。

ステルスゲームのシステムや環境メカニクスの基礎についてさらに詳しく知りたい方は、[IGNのステルスゲーム詳細ガイド](https://www.ign.com)をチェックし、ワールドデザインが様々なジャンルで戦術的隠蔽にどのように影響を与えているかを確認してみてください。

| 順位 | スポット名 | 隠蔽レベル | 脱出難易度 | 最適な用途 |
| :---: | :--- | :---: | :---: | :--- |
| **1** | **偽の梁からのドロップダウン** | 高 | 極めて容易 | 正面ドアから侵入してくるレイダーへの頭上奇襲 |
| **2** | **階段下ストレージキャビティ** | 中 | 困難 | 急なクリアリング時の土壇場のしゃがみ隠伏 |
| **3** | **通気ダクトの折り返し** | 高 | 普通 | 外部突破後に居住区画へ再侵入するためのルート |
| **4** | **二重壁パーティションの隙間** | 極めて高 | 極めて困難 | 高価値アイテムコンテナの安全な隠匿 |
| **5** | **外壁オーバーハングプランター** | 中 | 極めて容易 | 屋内索敵に引っかからずに接近者を監視 |

### 1. 偽の梁からのドロップダウン
マップ本来の天井より半ブロック低い位置に天井を構築することで、平らな這い込みスペースを作り出します。ドアを勢いよく突破してきたレイダーが真上を見上げることは稀なため、囮部屋へ駆け込んだ敵の背後に飛び降りて奇襲できます。

### 2. 二重壁パーティションの隙間
壁パネルを1ユニット分の歩行スペースを空けて平行に2枚設置することで、家具の裏側に隠し通路を作成します。継ぎ目の上にインタラクト可能な装飾（ワードローブや大型の絵画など）を配置すれば、通路の存在を完全に不可視化できます。

## 防衛型ベース建築：レイダーを迷わせるレイアウト

侵入不可能な拠点の設計とは、単純な耐久性の高さではなく「心理的な誘導」がすべてです。一本道のダンジョンのような構造にしてしまうと、レイダーは爆発物や銃撃で隅々までシステマチックにクリアリングしていきます。目指すべきは、侵入者に「主要な保管庫はすでに漁り尽くされた後だ」と錯覚させることです。

| 部屋タイプ | 主な機能 | 欺瞞性 | 推奨トラップの組み合わせ |
| :--- | :--- | :--- | :--- |
| **侵入口エアロック** | 集団での一括突破を制限 | 低 | スプリングボード、落とし穴トラップ |
| **囮の保管庫（ベイトヴォルト）** | 価値の低い未施錠アイテムを露出 | 極めて高 | トリップワイヤー警報、偽のバリケード |
| **行き止まり迷路** | 敵のスタミナと弾薬を消耗させる | 中 | 見えない段差、視界遮断スモーク発生器 |
| **内部セーフルーム** | 本物の物資保管およびサバイバルバンカー | 高 | 隠しハッチドア、静音キーパッド |

### 「オニオンレイヤー（玉ねぎ型多層）」防衛戦略

1. **外層（アウターシェル）：** すでに略奪されたか放棄されたように見せるため、安価で劣化した建築素材を使用します。
2. **中間層（ミドルレイヤー）：** 錯覚を完璧にするため、分かりやすい通路、ガラクタが入った鍵のない木箱、意図的に破壊された壁などを配置します。
3. **コア層（コアシェル）：** 不規則な岩壁や窪んだ装飾アセットの背後に構築します。継ぎ目からプレイヤーのシルエットが漏れないよう、照明は一切設置しません。

このレイアウトを導入することで、敵が建物を下見・偵察した際にも、あなたの存在を完全に悟らせずに済みます。

## 心理戦：敵の誘導とポジションの奪還

防衛戦で勝利を収めるには、建築メカニクスと同じくらい心理戦が重要です。**拠点を隠し、潜伏場所を奪う**戦術を選択することは、レイダーの思い込みを逆手に取る行為に他なりません。自信過剰な攻撃者は「中に隠れている者はパニックに陥り、隅に追い詰められているはずだ」と油断して突入してきます。

```
ステップ1: セクションAで意図的に物音を立てる（足音、ドアの開閉音）。
ステップ2: 明かりのない連絡シュートを通ってセクションBへ滑り込む。
ステップ3: 攻撃者がセクションAに向けて重火器を撃ち込むのを待つ。
ステップ4: セクションCにある攻撃側の足場・拠点を奪い、退路を封鎖する。
```

熟練プレイヤーは「音の管理」が勝敗を分けることを熟知しています。床に不要なアイテムを落としてカサカサという音を立てれば、敵を狭いキルゾーンへ誘い込むことができ、その隙に検知されることなく開けた中庭を移動して配置転換を完了できます。

## 拠点要塞化のためのクイックチェックリスト

ログアウトする前やレイドの防衛態勢に入る前に、この実践的なチェックリストを実行して、猛烈な索敵に対抗できるか確認してください。

- [ ] 屋内の照明によって、外に面した窓にプレイヤーの影が投影されていないか。
- [ ] 二重壁の隙間は周囲と同一のテクスチャで密閉され、継ぎ目が消えているか。
- [ ] 正面入口付近に、低ティアのガラクタを入れた囮チェストを1つ以上配置したか。
- [ ] すべての垂直ドロップダウン地点で、ブロックを設置せずに自力でジャンプして戻れるかテストしたか。
- [ ] 全ての通路をしゃがみ歩きし、家具に引っかかって勝手に立ち上がってしまう場所がないか確認したか。
- [ ] 壁を突き抜けて（クリッピングして）外から潜伏を察知される原因となる草木を刈り取ったか。

このチェックリストを用いて定期的に要塞を点検することで、隠れ場所を露呈させてしまう典型的な建築ミスを未然に防ぐことができます。

## よくある質問（FAQ）

### 「拠点を隠して潜伏場所を奪う（hide ur base and steal hiding spots）」とはどういう意味ですか？
この戦術は、隠蔽された拠点建築とアクティブな側面攻撃（フランク）を組み合わせたものです。静的なバンカー内に閉じこもるのではなく、攻撃を受けている最中に隠し通路から脱出し、レイダー側が安全だと過信している高所、遮蔽物、あるいは脱出地点を先回りして制圧するプレイスタイルを指します。

### 三人称視点ピーク（カメラ覗き見）で潜伏場所を見破られないようにするには？
天井の高さを低く保ち（キャラクターの身長の2〜2.5倍以下）、障害物のない直線的な長い廊下を避けてください。アーチ状の梁、低く吊るされたシャンデリア、直角のクランク（90度ターン）を設けることで、仮想カメラが障害物を回り込んで覗き見るのを防ぎ、部屋を確認するために敵自身が体を露出せざるを得ない状況を作れます。

### 拠点を隠して潜伏場所を奪おうとする際、最も犯しやすいミスは何ですか？
出入り口が1箇所しか存在しないことです。唯一のドアを攻撃側に突破された場合、自ら作った隠れ場所の中で袋のネズミになってしまいます。隠されたセーフルームには、必ずマップの別区画へと繋がる緊急脱出用ハッチを設けておく必要があります。

### 隠し壁の中にいるとき、方向転換や周囲を見渡す音はレイダーに聞こえますか？
大半のサバイバル系ゲームエンジンでは、視点を回転させたりインベントリ内のアイテムを切り替えたりするだけでも微小な環境音が発生します。しゃがみ移動を行えば足音は完全に消せますが、コンテナを開けたり大型装備を取り出したりすると、ヘッドセットを装着した近くのプレイヤーに位置を特定される恐れがあります。脅威が通り過ぎるまでは、あらゆるアクションを最小限に抑えてください。
