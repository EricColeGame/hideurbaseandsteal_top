## コアゲームプレイの仕組み：潜入の基本ループ

本作の基礎は、拠点防衛と積極的なリソース略奪の絶え間ないバランスの上に成り立っています。秘密のポータルが地上マップとプライベートなポケットディメンションを繋いでいます。

```
[リスポーン / 地上世界] ──> [秘密マーカーを設置] ──> [異次元ベース]
         │                                                    │
         ▼                                                    ▼
[ライバルのマーカーを探索] ──> [潜入＆ペットを奪う]    [ペットを管理＆防衛強化]
```

地面のポータルを通ると、自分だけの保管庫に入れます。内部ではペットがコインを受動的に生成してくれます。しかし、地上マップ上にはあなたの入口マーカーが表示されたまま残ります。ライバルにそれを見つけられると、ポータルを踏んで直接あなたの部屋に侵入され、保護されていないアセットを強奪されてしまいます。

| ゲームフェーズ | 主要目標 | リスクレベル | 推奨されるプレイスタイル |
| :--- | :--- | :--- | :--- |
| **マーカーの隠蔽** | 拠点の入口を目立たない場所に設置する | 高（常時） | 自然の遮蔽物や影を活用する |
| **保管庫での生産** | ペットの購入、アップグレード、保管 | 低（保管庫内） | 分あたりの通貨生成効率を最大化する |
| **マップ偵察** | 地上を探索して他プレイヤーの入口を探す | 中 | 定番の隠し場所や地形の継ぎ目を覚える |
| **アクティブレイド** | 敵拠点に潜入し、上位ペットを奪って脱出 | 高（時間制限あり） | 最速の脱出ルートと高価値ターゲットを特定する |

コミュニティの報告によると、保管庫の中にずっと籠もっていると誤った安全感にとらわれがちです。室内にいる間は、地上マップでポータルの周囲をうろつくライバルを監視することができません。防衛のための偵察と、受動的なコイン回収の時間をバランスよく配分することが不可欠です。

## 拠点を隠す方法：地形選びとマーカーの配置

ポータルを置く場所の選定は、ゲーム内で最も重要な防衛上の決断です。初心者はリスポーン直後にテレポートパッドを落としてしまい、誰の目にも明らかな標的を晒してしまうことがよくあります。

### 隠蔽の地理学

上級プレイヤーは、視界の遮蔽、カメラの当たり判定の隙、照明の死角などを巧みに利用します。強固な**hide ur base and steal secure base**の環境を維持するためには、リスポーン地点のハブや中央ショップなど、人通りの多いエリアを避けてください。

| ロケーションタイプ | 安全度ランク | メリット | デメリット |
| :--- | :--- | :--- | :--- |
| **開けたリスポーン広場** | F | 自分で見つけやすい | スポーンしたプレイヤーに即座に見つかる |
| **オブジェクトや壁の裏** | C+ | 直線的な視線を防げる | 念入りに探索するスカウトに頻繁にチェックされる |
| **茂みや木の天辺** | B+ | 視点を回さないと判別しにくい | 描画のブレで当たり判定が見えてしまう場合がある |
| **マップ外周の地形の端** | A- | 一般のレイド勢が通るルートから外れる | 追い詰められたときの逃げ道が限られる |
| **隠れた亀裂や深い影** | S | 高いカメラアングルでないとほぼ見えない | 設置するためにアスレチック（パルクール）技術が必要 |

### マーカー設置の必須ルール

*   **平坦な地平線を避ける：** 草地や床とマーカーのカラーアウトラインがはっきりと対比してしまうような均一なテクスチャの上には、絶対にマーカーを設置しないでください。
*   **環境の障害物を活用する：** 自然の岩山の間、倒木の下、装飾用オブジェクトの奥深くなどにマーカーを配置しましょう。
*   **パーティクルエフェクトに注意する：** 一部のアイテムやプレイヤーの軌跡（トレイル）エフェクトは発光し、ポータルパッドへの直接の手がかりになってしまうことがあります。
*   **定期的に場所を変える：** ライバルに拠点へ入るところを目撃された場合は、すぐにマーカーをマップの別の区画へ移動させてください。

## セキュアベースの構築：内部レイアウトとペット防衛

ポータルを外に安全に隠したら、次は素早い強盗レイドに対抗できるよう保管庫の内部構造を整えなければなりません。カモフラージュを突破されて侵入された場合、内部の構造が財産を守るセカンドラインとして機能します。

```
                  [敵がポータルから侵入]
                            │
                            ▼
               [ゾーンA：おとりの低ランクペット] ──(最初に奪われる)
                            │
                            ▼
             [ゾーンB：障害物 / 狭い通路]
                            │
                            ▼
               [ゾーンC：高ランクペット / 最深部]
```

このような段階的な防衛ラインを構築することで、迎撃のための猶予時間が生まれます。敵が**hide ur base and steal secure base**の保管庫に侵入した際、最初に安価なおとりペットに遭遇させることで、最も稼ぎ頭となる高価な資産を部屋の奥深くに守ることができます。

### 内部防衛プランの比較

| 内部レイアウト | 構築コスト | 防衛効果 | 防衛時の挙動 |
| :--- | :--- | :--- | :--- |
| **未整理の乱雑配置** | 無料 | 極めて低い | ペットが散乱し、敵に最高ランクのペットを即座に奪われる |

大型アップグレードのためにコインを貯めている最中は、常に警戒態勢を維持してください。自分が室内にいるときに侵入者が現れた場合は、即座に立ちふさがってブロックするか、最も貴重なペットを抱えて相手の届かない安全な場所に退避させましょう。

## レイド＆潜入：ライバル拠点からの強奪

強力な防衛は、実りある攻撃によって支えられます。経済を急速に成長させるには、ショップでの地道な購入だけに頼るのではなく、ライバルの保管庫を偵察して略奪することが大きな起爆剤となります。

### ライバルの隠れ家を見つける方法

効率的なレイドを行うには、防衛側プレイヤーが使いそうな隠し場所を逆算して考えます。マップの境界線、頭上の建造物、主要ランドマークの裏にあるテクスチャの死角など、通常の視線から外れたエリアをスキャンしましょう。

1.  **高所から見渡す：** 高い構造物に登って鳥瞰視点で地形を観察し、特徴的なポータルの輪郭を探します。
2.  **地形の継ぎ目を調べる：** プレイヤーがマップの角に埋め込むようによくパッドを隠す、壁の根元や崖の縁に沿って歩いてみます。
3.  **怪しい動きを追跡する：** プレイヤーが何もない空中で突如消えるのを見かけたら、その地点へダッシュしてください。ほぼ確実にそこにポータルマーカーがあります。
4.  **素早く回収して脱出する：** 相手の保管庫に足を踏み入れたら、瞬時に最高ティアのペットを特定して掴み、拠点の持ち主が気づいて反撃してくる前に脱出しましょう。

| ターゲット拠点の種類 | 潜入難易度 | 平均戦利品品質 | 推奨事項 |
| :--- | :--- | :--- | :--- |
| **無警戒な初心者** | 低 | 低ティア | ウォーミングアップの手軽な資金源だが実入りは少ない |
| **アクティブな中盤タイクーン**| 中 | 中〜高ティア | 最重要ターゲット。リスクとリターンのバランスが良い |
| **要塞化したベテラン拠点** | 高 | ウルトラレア | 高リスク。素早い略奪テクニックが必須 |

レイドは根本的にスピードの勝負です。相手のコレクションを物色するのに時間をかけすぎると、見つかる確率が高まるだけでなく、地上にある自分のマーカーが無防備なまま放置されることになります。

## 上級戦略：心理戦とパトロール

**hide ur base and steal secure base**の基本をマスターしたら、常習的なレイド勢に対して高度な心理戦を仕掛けることができます。

*   **おとりマーカーの罠：** 一見隠れているように見えつつ、近くの有利な地点から射線が通っている場所に入口パッドを置きます。周囲で待機し、ポータルに近づいてきた侵入者を奇襲しましょう。
*   **目立たないアバター設計：** 周囲の岩や地形のカラーパレットに溶け込む、シンプルで暗いローポリ系のアバターコスメを装備します。巨大でネオンのように光るスキンは、遠くの描画距離からでも格好の目印になってしまいます。
*   **尾行防止プロトコル：** 視界内に他のプレイヤーがいる場合は、絶対に自分のポータルマーカーに向かって直進してはいけません。拠点を通り過ぎ、地形の裏を回り込んで誰も見ていないことを確認してから、自拠点へと足を踏み入れましょう。
*   **サーバー移動（サーバーホップ）：** 特定のエリアを集中的に狙う好戦的なレイド勢が同じサーバーにいる場合は、別のインスタンスに移動してペット経済を安全に育ててから、競争の激しいロビーに戻るのが賢明です。

真に難攻不落な**hide ur base and steal secure base**を築くには規律が求められます。巧みな地形隠蔽、階層化された内部防衛、そして隙を逃さないマップ偵察を組み合わせることで、自分の資産を守り抜きながら、ライバルの保管庫を軽々と攻略していきましょう。

## よくある質問（FAQ）

### 拠点を隠し、安全なベースを築くために最も重要なステップは何ですか？
最も重要な要素はポータルの配置場所です。開けた場所、明るい場所、一般的な移動ルートの近くには絶対にマーカーを置かないでください。自然の遮蔽物、影の中、凹凸のある不規則な地形の隙間に埋め込むことで、索敵中のプレイヤーに偶然発見されるのを防ぐことができます。

### 自分が保管庫の中にいても、他のプレイヤーにペットを盗まれますか？
はい。他のプレイヤーが地上であなたのマーカーを見つけてその上に乗ると、あなたが室内にいるかどうかに関係なく、保管庫の内部へ直接テレポートしてきます。侵入者は保護されていないペットを拾って出口から逃げることができるため、プレイヤー自身が立ちふさがって妨害するか迎撃する必要があります。

### 隠していたマーカーがライバルに見つかってしまったらどうすればいいですか？
直ちに拠点のマーカーを移動させてください。一度場所を特定されると、そのプレイヤーは新しく購入されたペットがないか確認するために定期的に戻ってきます。高ティアの資産をインベントリに退避させるか、ポータルをマップのまったく異なる区画へ移設してください。

### レイド被害に遭った後、素早く立て直すにはどうすればいいですか？
すべてのペットを保管庫の床に出しっぱなしにするのではなく、予備のスターターペットや中盤ティアのペットをセカンダリストレージにキープしておきましょう。また、マップ上の警備が手薄な初心者拠点をターゲットにして、カウンターレイド（報復略奪）を行うことで失った資産を素早く補填することも可能です。
