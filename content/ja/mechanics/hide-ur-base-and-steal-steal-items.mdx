## コアゲームループ：拠点と略奪（強盗）の仕組み

しかし、入口を誰の目にも触れる場所に放置しておくのは、自ら危険を招くようなものです。他のプレイヤーはこれらのマーカーを探してマップ内を絶えず捜索しています。もし対戦相手があなたのマーカーを踏むと、即座に拠点内部への侵入を許してしまい、保護されていないペットを奪われてしまいます。拠点の防衛と攻撃的な探索のバランスをどう取るかという点に、本作ならではの緊張感があります。

## 拠点入口を隠す場所とテクニック

拠点の入口は、ワープポータルとして機能するフィールド上の可視マーカーです。中央の通路、リスポーン地点、開けた平原など、人通りの多いエリアに設置してしまうと、わずか数秒で対戦相手に見つかってしまいます。**拠点を隠してアイテムを盗む（hide ur base and steal steal items）**戦略を成功させる第一歩は、他プレイヤーの射線（視界）を遮る地形を選ぶことです。

```
地形偵察チェックリスト:
1. 主要なハブエリアからの射線を遮断できているか
2. 自然の地形（崖、オーバーハング、影など）を活用しているか
3. 人気のリソーススポーン地点の近くを避けているか
4. カメラアングルを調整し、遠くからマーカーが見えないか確認したか
```

## レイドの技術：侵入してアイテムを盗み出す方法

略奪（強盗）は、ゲームの進行を一気に加速させる手段です。序盤の低ティアペットで地道に現金を稼ぐ代わりに、上級プレイヤーの施設に忍び込めば、高収益のペットを一瞬で手に入れることができます。効率的に**拠点を隠し、アイテムを盗み出す（hide ur base and steal steal items）**には、素早い偵察ルートの巡回をマスターする必要があります。

1. **手持ちを空にする**: 遠くからでも位置がバレてしまうような大型コスメティックや発光するツールは外しておきます。
2. **周囲をスキャンする**: 自然の尾根や高い足場に沿って走り、よくある隠し場所の隙間を見下ろすように探します。
3. **ターゲットのポータルを特定する**: 崖際や茂みに紛れているわずかな色の変化や、インタラクト表示を見逃さないようにします。
4. **侵入と脱出**: ポータルを踏み、素早く相手のペット囲いへ移動し、最も価値の高いペットをつかんでオーバーワールドへ脱出します。

## 上級戦術：拠点防衛と襲撃のバランス

熟練プレイヤーは、このゲームを「経済レース」として捉えています。拠点の中に引きこもっていればペットは守れますが、他者からの略奪によってコレクションを増やすことはできません。逆に、索敵ばかりに時間を費やしていると、入口を見つけられた際に自分の拠点が無防備になってしまいます。

遅れを取ることなく上手に**拠点を隠し、アイテムを盗む（hide ur base and steal steal items）**には、ゲームプレイを時間ごとに区切って立ち回るのが効果的です：

```

- 70%：索敵と積極的な強盗
- 20%：拠点の強化＆ペット合成
- 10%：マーカーの再配置＆安全確認
```

### 拠点マーカーの定期的な移動

入口マーカーを同じ場所に15〜20分以上放置することは絶対に避けてください。略奪されたプレイヤーはポータルのおおよその位置を覚えており、必ず復讐に戻ってきます。マーカーを回収し、2〜3セクター離れた予想外の新しい隠し場所に再設置しましょう。

| プレイヤーの行動 | よくある失敗 | 対抗戦略 |
| :--- | :--- | :--- |
| **復讐の標的になる** | アイテムを盗んだ後も同じ場所に留まる | 強盗に成功したら即座にマーカーを移動させる。 |
| **ポータル待ち伏せ** | 人気のショップ付近にマーカーを置く | マップの端や高い足場などの垂直スペースへ移動する。 |
| **欲張りな略奪** | 価値の低い初期ペットまで拾ってしまう | 逃走時間を確保するため、エピックやレジェンダリーのみに絞る。 |
| **無防備な放置** | オープンな拠点内でAFK（放置）する | レアペットを安全な金庫に保管するか、プライベートサーバーへ移動する。 |

迅速な拠点移動、賢いポータル配置、そして高価値ターゲットの選別を徹底することで、自分の資産を安全に保護しながら、敵の隠れ家からシステマチックに戦利品を奪い尽くすことができます。

## よくある質問（FAQ）

### 他のプレイヤーに拠点のポータルが見つかるとどうなりますか？
相手があなたの入口マーカーを発見した場合、そのマーカーを踏むだけであなたの拠点内部へ侵入できます。侵入者は拠点内のペットにインタラクトして盗むことが可能です。これを防ぐには、人里離れた視界の通らない場所にマーカーを設置してください。

### ソロプレイヤーが効率的に拠点を隠し、アイテムを盗むにはどうすればよいですか？
ソロプレイヤーは、精密なパルクールジャンプが必要な高所の隠し場所を狙うのがベストです。地上から離れた高所に入口を確保したら、低地の谷をステルスルートで移動し、隠し方の甘い敵のポータルを探し出しましょう。

### 盗んだアイテムを持ち帰った後、相手に奪い返されることはありますか？
はい、あります。盗んだペットは拠点内の囲いに配置されます。被害者（または別のライバル）があなたの新しい拠点を見つけ出した場合、侵入されて奪い返される可能性があります。拠点の入口を定期的に移動させることが、報復を防ぐ最善策です。

### 拠点が何度も襲撃される場合の最適な対処法は？
拠点が繰り返し突破される場合は、すぐにサーバーを変更するか、マップの最果ての隅にポータルを移設してください。また、拠点のアップグレード購入に資金を集中させ、最高収益のペットのみを配置し、低ランクのペットは予備ストレージに退避させておきましょう。
