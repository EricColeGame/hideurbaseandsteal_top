## Hide Ur Base and Steal における拠点設置の仕組み

最適な場所を探す前に、拠点ポータルのメカニクスを理解しておく必要があります。マップにロードされると、プレイヤーは設置可能なマーカーを所持しています。このアイテムを使用すると、地表に専用の入り口タイルが埋め込まれます。その上を通ると瞬時に地下のプライベートバンカーへとテレポートし、そこでペットたちが通貨を生成します。

しかし、徘徊している泥棒にポータルを見つかってしまうと、誰でも中に入り込んであなたの領地に侵入し、苦労して手に入れたペットを奪い去ることができてしまいます。入り口が遮るもののない平地や中央の通路沿いにある場合、ほんの数秒で部屋の中身がすべて略奪されてしまうでしょう。

### 拠点ポータルの基本ルール

* **衝突判定とクリッピング:** マーカーを完全にソリッドな地形オブジェクトの内部に埋め込むことはできませんが、低く垂れ下がったオブジェクトや半透明の地形メッシュの下に滑り込ませることは可能です。
* **距離制限:** 他のプレイヤーのアクティブなマーカーに直接重なるような位置に入り口を設置することはできません。
* **即時インタラクション:** ポータルに入るための起動時間はなく、範囲上をキャラクターが通過した瞬間に内部へテレポートします。

## 詳細マップ解説：おすすめの秘密スポット TOP 3

ペットの収入を徹底的に守るには、一般プレイヤーのカメラアングルが死角になる地形の特性を活かす必要があります。経験豊富な侵入者たちの報告に基づき、特に優れた3つのエリアを詳しく解説します。

### 1. 水没した滝の窪み (The Sunken Waterfall Alcove)

滝のエリアには、激しい水流のパーティクルエフェクトと険しい崖の端が存在します。水のカーテンの裏側に滑り降りるか、濡れた岩の張り出しの真下にマーカーを押し込むことで、ポータルのテクスチャが背景に完全に同化します。大半の襲撃者は水辺沿いをダッシュで駆け抜けるだけで、流れ落ちる水の幕の裏側までわざわざ確認しようとはしません。

### 2. 高木の死角 (The Vertical Canopy Blindspot)

マップ内にはいくつかの大きな装飾用の木が点在しています。簡単な壁ジャンプや枝渡りをマスターして厚い葉の層に到達できれば、高い枝の上や葉の合流地点に直接マーカーを設置できます。一般的な略奪者はカメラを進行方向の正面ややや下（草地）に向けて走る傾向があるため、頭上高い位置にあるマーカーはサーバー内の90%のプレイヤーの視界に入りません。

### 3. 深い峡谷の岩壁の裂け目 (Deep Canyon Wall Crevice)

岩場の境界線に沿って、ゴツゴツとした岩の継ぎ目が自然なV字型の影を作り出しています。この窪みの中にタイルを配置することで、遠距離から見たときに入り口マーカー特有の発光を目立たなくさせることができます。岩壁に顔を擦り付けるようにして境界ギリギリを歩いてこない限り、誰も気づかずに拠点の横を通り過ぎていくでしょう。

## 敵拠点の偵察と潜入ルート

自分の拠点を守ることは戦いの半分にすぎません。施設をアップグレードするためには、ライバルの金庫を突き止めてペットを奪い取る必要があります。優れた拠点ハンターは無目的に歩き回るのではなく、体系的な偵察ルートを巡回します。

```
[マップ外周リング] ──► 岩の継ぎ目や境界線をチェック
         │
         ▼
[水辺・川の流域]    ──► 滝の裏や橋の下を捜索
         │
         ▼
[高い木々／小道具]  ──► 木の枝やオブジェクトの裏側をスキャン
         │
         ▼
[金庫へ潜入]        ──► 高ティアのペットを奪取して脱出
```

ライバルの拠点を探すときは、地上マーカーの描画距離が短くなって消えてしまわないよう、グラフィック設定をある程度高めにしておきましょう。また、プレイヤーの動きにも注目してください。アバターが岩肌の近くで突然フッと消えた場合、そのすぐ近くに入り口があることは確実です。

## 防衛戦略の比較：カモフラージュ vs 距離

マップ中央付近の小道具の陰に巧妙に隠れるべきか、それとも外周の端に建てるべきかは、すべてのプレイヤーが悩むポイントです。これらの **hide ur base and steal base locations** のメリットとデメリットを比較して、プレイスタイルに合った最適な構成を見つけましょう。

| 戦略指標 | 外周戦略（距離重視） | カモフラージュ戦略（目の前の死角） | 高所立体配置（パルクール） |
| :--- | :--- | :--- | :--- |
| **ペット保管にかかる時間** | 遅い（移動に45〜60秒） | 速い（移動に10〜15秒） | 普通（移動に20〜30秒） |
| **初心者による発見率** | 稀 | 普通 | 極めて稀 |
| **上級者による発見率** | 高い（まず外周を探すため） | 稀（カメラアングルに依存） | 低い（登る姿を見られない限り） |
| **防衛時のリカバリー** | 発見されると困難 | 素早い対応が可能 | マーカー入り口で待ち伏せしやすい |
| **おすすめ装備** | スピードブースター | おとりマーカー | ジャンプコイル / 移動系ギア |

## 拠点内部でペットを守る方法

どれほど優れた **hide ur base and steal base locations** を選んだとしても、鋭いプレイヤーに跡をつけられ、場所を特定されてしまう可能性はゼロではありません。拠点の防衛は入り口だけで終わるものではなく、内部レイアウトの工夫も不可欠です。

```
       [ポータル入り口]
               │
         ▼ (チョークポイント)
       [狭い通路]        ◄── トラップや障害物の設置
               │
         ▼
       [メイン金庫室]
     ┌───────────────┐
     │ 低ティアペット │  ◄── おとりの展示スペース
     └───────┬───────┘
             │
             ▼ (隠された奥の角)
     ┌───────────────┐
     │ 高ティアペット │  ◄── 安全な最深部
     └───────────────┘
```

1. **ペットの配置を分散させる:** 最も収益の高いペットを、入り口のテレポートパッドのすぐ隣に配置してはいけません。侵入者が拠点の奥深くまで歩かなければならない構造にし、犯行現場を押さえる確率を高めましょう。
2. **マーカーを定期的に移動する:** 誰かにつけられた疑いがある場合は、一旦地上に出てマーカーを回収し、ティアリストにある別の優れた **hide ur base and steal base locations** へと拠点を移転しましょう。
3. **おとりを活用する:** 入り口の近くには、安価で一般的なペットを数体置いておきます。焦っている泥棒は最初に目に入ったペットを慌てて掴んで逃げていくことが多く、奥深くに隠された激レアペットが無傷で残るケースが多々あります。

## よくある質問（FAQ）

### 他のプレイヤーに見つかった場合、ポータルを勝手に動かされたりしますか？
いいえ。他のプレイヤーがあなたの設置したマーカーに干渉したり、削除したりすることはできません。ただし、入り口が見つかると中に入られて無防備なペットを略奪されてしまうため、安全な **hide ur base and steal base locations** を選ぶことが何よりも重要です。

### 拠点のマーカー前で待ち伏せ（キャンプ）されている場合はどうすればいいですか？
地上の入り口付近で誰かが張り込んでいる場合、すぐに金庫から外へ出てはいけません。ゲーム内のリセット機能やショップメニューからマーカーを回収して拠点を移転するか、別のサーバーに切り替えて奇襲を受けるリスクなしに手持ちのインベントリを守りましょう。

### グラフィック設定によってマーカーの見つけやすさは変わりますか？
はい。グラフィック品質を下げると、細かい草や影のシェーダーが非表示になり、茂みの中に隠したマーカーが露出してしまう場合があります。逆にテクスチャの鮮明度を上げておくと、峡谷の壁などに隠された敵ポータルのわずかな縁を視認しやすくなります。

### 1回のプレイでどのくらいの頻度で拠点を変えるべきですか？
プレイヤーの経験則に基づくと、20分〜30分おきにポータルを移動させるのが理想的です。人の多いサーバーには、有名な隠しスポットを定期的に巡回する熟練スカウトが存在します。外周の裂け目と高所の死角の間でマーカーをローテーションすることで、金庫の安全を保ち続けることができます。
