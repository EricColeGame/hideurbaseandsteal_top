## 拠点の隠蔽とオブジェクトアンカーの仕組み

あなたの金庫（保管庫）は、マップの地形内に直接建てられた物理的な要塞ではありません。マップ各所に配置された一般的な環境オブジェクトに紐づけられた、インスタンス化されたプライベートルームとなっています。この「アンカー」を操作することで拠点内へ直接テレポートし、内部の展示パッドに配置されたペットたちがキャッシュを自動生成します。ただし、室内に入ると入り口の真上にプレイヤー名が表示されるため、擬態された入り口をクリックした対戦相手は、そのままあなたのコレクションルームへと足を踏み入れることができます。

どのアンカーを選ぶかによって、通りすがりのプレイヤーに入り口を偶然見つけられる確率が大きく変わります。また、奪った戦利品を金庫へ持ち帰る際、ゲーム内では空中に浮かぶ黄色いマーカーや地面に光る誘導矢印が表示されます。このガイドラインは帰還ルートをスムーズにしてくれる一方で、あなたの後を追うプレイヤーがいれば、入り口までの経路をそのまま辿られてしまう危険性も孕んでいます。

| コア要素 | ゲームプレイ機能 | 戦略的考慮事項 |
| :--- | :--- | :--- |
| **インタラクティブ・プロップアンカー** | 拠点金庫へ通じる偽装ポータルとして機能 | ランダムなクリックを防ぐため、視覚的に目立たないものである必要がある |
| **ユーザーネーム表示ラベル** | プライベートルームの所有者を識別 | 誰の拠点を略奪しているのか侵入者に即座に通知される |
| **地面のルート矢印** | 盗んだアイテムを運ぶプレイヤーを誘導 | 追跡者がいる場合、隠し場所が露呈する原因となる |
| **パッシブインカムパッド** | 家畜やペットを展示して現金を自動生成 | 敵の侵入者が狙う最大のターゲット |

プレイヤー心理を理解することは、優れた隠し場所を選ぶための基本です。大半の襲撃者はメインストリートを駆け抜け、開いたドアを覗き込み、ルート上にあるオブジェクトを手当たり次第にクリックして調べます。入り組んだ部屋の奥深くや、壁の高い位置、あるいは目立たない自然の地形に紛れ込ませたオブジェクトは、意図的に探索しなければ見つからないため、偶然発見される確率を大幅に減らすことができます。

## 拠点を移転すべきタイミングと方法

永遠に安全な隠し場所など存在しません。他のプレイヤーに虚空へと消え去る瞬間を目撃された時点で、そのアンカーは完全に危険に晒されています。安全を維持するためには、貴重なアイテムを奪われた後の緊急対応としてではなく、定期的なルーティンとして移転を行う必要があります。

高額な報酬を得たとき、高価なペットを手に入れたとき、または重要な節目に到達したときは、即座に入り口の場所を変更すべきです。マップを探索するゲーム全般におけるアカウント育成や効率的な立ち回りについては、[IGN](https://www.ign.com/) の詳細ガイドなども参考に戦術を磨いてみてください。

             ▼

### 移転を検討すべき重要なトリガー

* **直接の追跡:** 戦利品を持って帰還中に追跡された場合、絶対に拠点に入ってはいけません。敵を引き離して視線を切り、即座にアンカーを変更してください。
* **転生（Rebirth）達成後:** 転生すると収益効率が跳ね上がります。価値が高まるほど好戦的な襲撃者を引き寄せるため、古い場所のままでは危険です。
* **サーバー内の異変:** 自分の活動エリア周辺で他プレイヤーの動きが活発になったと感じたら、対角線上にある反対側の区画へ入り口を移動させましょう。
* **防衛戦の発生後:** 金庫内に侵入され、仮に撃退できたとしても、相手にはすでにアンカーの場所が割れているため、再び襲撃に来る可能性が極めて高いです。

| 移転フェーズ | 実行アクション | 避けるべきよくあるミス |
| :--- | :--- | :--- |
| **1. 脱出** | 敵の動きが止んだ隙に出口へ向かい、周辺を索敵する | 近くで戦闘音がしているのにそのまま外へ飛び出す |
| **2. 移動** | マップ外周の障害物沿いなど、目立たないルートを通る | スナイパーやダッシュ中の敵に見えやすい大通りを走る |
| **3. 設定** | 完全に別の区画にあるオブジェクトを選択する | 同じ建物内にある別のオブジェクトに変えるだけで済ませる |
| **4. 確認** | 黄色のウェイポイントが新しいアンカーを指しているか確認 | 操作テストをせずに移転が完了したと思い込む |

## 15秒のログアウト猶予時間と安全な退出方法

すべてのプレイヤーが理解しておくべき極めて重要な仕様が「退出ディレイ」です。サーバーから退出したり接続が切断されたりしても、あなたの金庫は正確に15秒間、完全にアクティブな状態でマップ上に残り、略奪可能な状態が続きます。敵がドアの外に立っているときにゲームを強制終了したりメニューに戻ったりしても、レイドを回避することはできません。

この仕様は、戦闘中の切断（コンバットログ）を防ぎ、プレッシャーに負けてパニックになったプレイヤーにペナルティを与えるために設計されています。敵にアンカーを特定された状態でクライアントを閉じると、展示パッドは完全に無防備な状態になります。襲撃者には、誰もいなくなった金庫に入り、最も価値の高いペットを略奪して脱出するための15秒もの時間が与えられてしまうのです。

| 脅威下の戦略 | リスク要因 | 推奨アクション |
| :--- | :--- | :--- |
| **強制切断（Alt+F4）** | 極めて危険 | 絶対に避けるべき。襲撃者に15秒間の自由な略奪を許すことになる |
| **定位置での防衛** | 高い | 装備が相手を上回っているなら、武器やトラップを構えて迎え撃つ |
| **緊急移転** | 普通 | 相手がアクションを起こす前に拠点を抜け出し、別の場所へ再設定する |
| **意図的なデスポーン** | 低い | 超レアな資産を手動で外す・処分して略奪を阻止する |

コミュニティの報告によると、好戦的なプレイヤーは判明している拠点の周囲を監視し、持ち主がログオフした瞬間に抵抗されることなく15秒間の略奪を行う手口を使うことがあります。もしドア前をキャンプする執拗なプレイヤーがいる不利なサーバーに入ってしまった場合は、防衛トラップを設置し、相手をリスポーンのループにハメている間に素早くアンカーをマップの辺境へと移転させ、それから安全にゲームを終了するのが最も確実です。

## 拠点防衛：アップグレード、転生、武器

金庫を守るには、オブジェクトの擬態だけでなく、能動的な防衛設備の導入が不可欠です。現金を稼いで転生を重ねることで、侵入者がお宝を持って逃走する前に無力化できる、さまざまな防衛ユーティリティや移動アイテムがアンロックされます。

転生を行うと所持金はリセットされますが、永続的な収益マルチプライヤーと強力な兵器へのアクセスが解放されるため、生存には欠かせません。武装による防衛を整えることで、発見されてしまった拠点を、油断した侵入者への致命的なトラップへと変えることができます。

| 装備カテゴリ | アイテム名 | 防衛における役割 | 戦略的有用性 |
| :--- | :--- | :--- | :--- |
| **近接武器** | 木製バット / スチールバット | 近接戦闘 | 展示パッドを物色している侵入者をノックバックさせる |
| **大型近接武器** | ゴルフクラブ | 高ダメージの防衛 | 室内に入ってきた軽装の略奪者を素早く排除する |
| **エリア封鎖** | トラバサミ（ベアトラップ） | 入り口の制圧 | 境界線を越えた侵入者を即座にその場に拘束する |
| **爆発物** | 爆弾 | 範囲攻撃による威嚇 | 徒党を組んで金庫を襲撃しようとする集団を一網打尽にする |
| **機動力** | スピードコイル | 高速な位置取り | 防衛時や戦利品の預け入れ時に素早く拠点へ戻れる |
| **移動補助** | グラビティコイル / グラップル | 垂直方向の回避 | 盗んだ資産を持ち帰る際、屋根を伝って逃走できる |

室内の防衛ラインを構築する際は、まず入り口のゾーニングから始めましょう。擬態オブジェクトから入ってきた直後の床にトラバサミを設置しておけば、足を踏み入れた侵入者を瞬時に拘束できます。動けなくなった無防備な相手には、スチールバットやゴルフクラブの追撃を叩き込みましょう。

## 襲撃戦術：ライバルの拠点への潜入

拠点防衛をマスターすることは、攻撃側のレイドをどのように仕掛けるべきかを理解することにも繋がります。他人の金庫を見つけ出すには、体系的な捜索ルートと、追い詰められたプレイヤーがどこにアンカーを隠しがちかという知識が必要です。

ハイレベルな襲撃者は、目立つオブジェクトには目もくれず、民家の奥、商業施設、そして不自然な屋外のオブジェクトを集中的に調べます。レイドを実行する際は、リスクを最小限に抑えつつ最大の価値を持ち帰ることを目指しましょう。戦利品を運ぶ間は地面の矢印が自分の拠点まで案内してくれますが、それは同時に道行く全員に自分の位置を知らせることにもなります。

```
ステップ1: 建物が密集した住宅街エリアに潜入する。
ステップ2: 通常とは異なるオブジェクト（時計、ランプ、家電など）をシステマチックにクリックする。
ステップ3: 拠点の金庫へ突入。レア、ミシカル、スピノサウルスなどの上位枠を最優先で狙う。
ステップ4: 帰還用に機動力装備（スピードコイルやグラップル）を構える。
ステップ5: 人通りの多い中央の大通りを避けつつ、地面の矢印に従って移動する。
ステップ6: 戦利品をパッドに配置。追跡されている場合は即座にアンカーを移転する。
```

### ターゲット資産の優先順位付け

価値の低いペットのために捕まるリスクを冒してはいけません。金庫の展示スペースには限りがあり、低ティアの動物を持ち帰ってもわずかな利益しか得られない割に、自分の位置を露呈させるリスクばかりが高くなります。ワニ、ミクロラプトル、ディメトロドン、あるいは1秒あたりの獲得キャッシュを大幅に引き上げてくれるレアなイベントペットなど、上位ティアの生物に狙いを絞りましょう。初期ペットしか置かれていない金庫だった場合は、自分の存在を悟られる前に即座に立ち去るのが賢明です。

## 拠点経済と展示パッドの管理

不労所得の生成効率は、最高峰の装備を揃えたり転生マイルストーンを達成したりするスピードに直結します。展示パッドは現在のアクティブな収益力を示しており、スロットの効率を管理することが素早い進行の鍵となります。

プレイ開始直後の数分間であれば、ネコ、モルモット、カエルといった初期の生物でスロットを埋めておくのも悪くありませんが、すぐに足かせとなります。低ティアのパッドはリターンが極めて少ないにもかかわらず、初心者の略奪者にとっては手頃な標的になってしまうためです。

| 入手方法 | コスト / 必要条件 | 収益の期待値 | リスクレベル |
| :--- | :--- | :--- | :--- |
| **初期購入（直接買い）** | 少額の固定現金（基本25ドル） | 低い（初期レート） | リスクなし・リターン低 |
| **投げ縄での野生捕獲** | 試行ごとに一定の手数料 | 中〜高 | 狩りの間、屋外で長時間無防備になる |
| **RNGマシンのガチャ** | 段階的に増加する通貨投資 | 高〜神クラス | 完全に安全。ただし運に左右される |
| **他プレイヤーの金庫潜入** | ハイリスク（対人戦闘あり） | 変動（ターゲット次第） | 極めて高い。死亡して装備を失うリスクあり |

プレイヤーの経験則として、序盤の資金をRNGマシンの永続アップグレード（特に運やスピードの倍率）に投資することが、最も長期的な費用対効果を生み出します。パッドが高収益の生物で満たされれば、拠点を死守するために必要なトラップ、バット、機動力アイテムなどを安定して購入し続けることができるようになります。

## 長期的な進行とサーバー内での立ち回り

サーバー内で優位に立ち続けるには、周囲のプレイヤーの動向に柔軟に適応する必要があります。もしロビー内に、スピードコイルを駆使してすべての住宅街を徹底的にキャンプするような極めて好戦的なプレイヤーがいる場合、同じ場所にとどまり続けるのは逆効果です。潔く別のサーバーへ移動するタイミングを見極めることが、蓄積した富を守ることに繋がります。

プレイを終了する前、または新しいロビーへ移動する前には、以下のチェックリストを確認してください。

- [ ] パッドから低ティアのペットを排除し、スロットごとの収益を最大化しているか。
- [ ] 入り口付近の防衛トラップがすべて作動可能状態になっているか。
- [ ] 現在のアンカー周囲を索敵し、拠点に入る姿を誰にも見られていないか。
- [ ] ログアウトする前に転生の必要条件を確認し、必要な資金を確保したか。
- [ ] 敵プレイヤーが自分のいる建物を捜索している最中に切断していないか。
- [ ] ログアウトする前に、入り口をマップ端の目立たない場所へ移転させて15秒の襲撃猶予を無力化したか。

隠蔽性、機動力、そして拠点経済を連動した1つのシステムとして捉えて立ち回ることで、ライバルの泥棒たちを出し抜き、揺るぎない富の帝国を築き上げることができるはずです。

## よくある質問（FAQ）

### 初心者におすすめの Hide Ur Base and Steal 最強の隠し場所はどこですか？
初心者には、住宅の2階にある寝室のランプや、マップ外周にある目立たない自然の岩が最も安全でおすすめです。大通りを駆け抜けるプレイヤーがこれらの場所を調べることはほとんどないため、序盤の資金を貯める間、安定して拠点を隠し通すことができます。

### 15秒ルールは拠点の隠し場所にどのような影響を与えますか？
ゲームを退出しても、金庫の入り口はマップ上に15秒間残り続け、他プレイヤーがアクセスできる状態になります。もしログアウトした瞬間にアンカーの近くに敵がいた場合、無抵抗のままペットを盗まれてしまいます。ゲームを終了する前には、必ず誰もいないマップの片隅へアンカーを移転させておきましょう。

### 襲撃者は私の後を追って隠し場所を特定できますか？
はい、特定可能です。盗んだペットを運んでいる間は拠点へ誘導する矢印が地面に表示されるため、追跡してきたプレイヤーにはあなたの目的地が丸見えになります。もし尾行されていることに気づいたら、アンカーには向かわず、移動アイテムを使って視線を切り、周囲の安全が完全に確認できるまで拠点へ戻らないようにしてください。

### 転生（Rebirth）は拠点のセキュリティにどう影響しますか？
転生すると所持金はリセットされますが、永続的な収益マルチプライヤーを獲得でき、トラバサミ、爆弾、強力な近接武器といった高性能な防衛装備がアンロックされます。これらの装備があれば、万が一アンカーを見つけられて室内に侵入されたとしても、自らの手で侵入者を返り討ちにすることが可能になります。
