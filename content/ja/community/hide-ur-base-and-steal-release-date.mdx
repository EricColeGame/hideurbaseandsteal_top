## コアゲームプレイ：ステルスタイクーンの仕組み

なぜ**hide ur base and steal release date**がこれほど大きな話題を呼んだのかを理解するには、そのユニークなゲームプレイサイクルに注目する必要があります。すべてのプレイヤーの拠点がマップ上の固定グリッドに配置される従来の形式とは異なり、本作はクラシックなタイクーンの成長要素にかくれんぼのギミック、そして本格的な拠点レイド（強奪）を融合させています。

```
隠し拠点のマーカーを設置  --->  内部に入ってタイクーンを拡張  --->  収益を生むペットを購入
           ^                                                               |
           |                                                               v
隠された入り口を防衛  <---  敵のマーカーを探索・潜入  <---  拠点を離れてレイドへ出撃
```

### ゲームプレイを支える3つの柱

1. **秘密のハッチの設置**：スポーン後、最優先すべきはマップ内の目立たず到達しにくい場所を見つけることです。プレイヤーは、内部のタイクーンへと直接つながる次元ポータルとなる、目に見えにくい・または目立たないマーカーを設置します。
2. **ペット経済の拡大**：自分だけのポケットディメンション（異空間）内でペットを購入します。これらのペットは時間経過とともに不労所得を生み出し、より速く動ける装備、高性能な探知機、上位ティアの生物を購入するための資金を提供してくれます。
3. **索敵と潜入**：自分の拠点の入り口を隠したら、公開マップへと繰り出します。茂み、壁の角、屋上、暗い路地などを入念に調べ、他のプレイヤーの進入ポイントを見つけ出すのが目的です。相手のマーカーを発見したら、内部へと足を踏み入れ、相手が気づいて対処する前に苦労して集めたペットを奪い取ります。
