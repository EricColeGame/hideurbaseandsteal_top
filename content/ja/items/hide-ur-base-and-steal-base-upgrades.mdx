## 基本メカニクス：拠点アップグレードとレイドの循環ループ

具体的な数値に入る前に、ゲームプレイの基本的なループを理解しておくことが極めて重要です。このゲームの根幹は、パッシブ収入の生成、地下アジトの隠蔽、そして他プレイヤーのポータルを探す地上探索という3つの要素の絶妙なバランスで成り立っています。

ゲームに参加したら、最初の仕事は秘密のフロアマーカーを設置することです。このマーカーを踏むと、プライベートな地下拠点へと直接テレポートします。内部では、時間経過で継続的にお金を生み出すペットを購入できます。しかし、地上のハッチが敵に見つかり、侵入されてペットを強奪されてしまえば、どれだけ収入が高くても意味がありません。

```
秘密マーカーを設置 ➔ 地下拠点へテレポート ➔ ペットを購入・装備 ➔ パッシブ現金を蓄積 ➔ 拠点をアップグレード ➔ ライバルの拠点を偵察・侵入
```

進行効率を最大化するには、高額なペットの購入とインフラ整備のバランスをうまく取る必要があります。[Roblox公式コミュニティガイドラインおよびプラットフォーム統計](https://en.roblox.com/)によると、この種のゲームではプレイヤー間のソーシャルな競争が継続率を高める要因となっており、生き残るためにはサーバー内の平均以上のペースを維持することが不可欠です。

### ペットスロット vs 金庫拡張

初心者がよく犯すミスとして、基本的なペット収容量を放置したまま侵入遅延トラップに過剰な投資をしてしまう点が挙げられます。ペットスロットを最優先で最大化することで、強力な高ティアペットを素早く購入するために必要な基礎収益力が手に入ります。そして、獲得ペースが保管上限を上回り始めた段階で、金庫のアップグレードが必須となります。

## レイダーの視点：防衛の裏をかき隠された拠点を発見するテクニック

自分の拠点を守ることはゲーム体験の半分にすぎません。他プレイヤーへのレイドを成功させれば、何時間もの退屈な作業をスキップして一気に富を得られます。相手プレイヤーがどのように拠点を構築しているかを知ることで、より効率的な強奪が可能になります。

1. **地面のポリゴンを注視する：** 基本的なポータルマーカーは、自然な地形と比べてわずかに浮き上がっていることがあります。草むらや岩の裂け目にある微妙なテクスチャのズレを探しましょう。
2. **不審な動きを追跡する：** 何もない壁に向かって走っていき、突然姿を消したプレイヤーを見かけたら、その場所に入り口マーカーが隠されています。
3. **移動速度アップアイテムを準備する：** 敵の拠点に侵入したら、スタンドに並んでいる最も収益の高いペットを素早く奪い、相手のショックトラップやテレポート防衛に捕まる前に脱出してください。
4. **迷彩を無力化する：** グラフィック設定の描画オブジェクト数を減らしたり、カメラを真上からの見下ろし視点に切り替えたりすると、カモフラージュされたフロアマーカーが地形の陰から浮き彫りになりやすくなります。

## 拠点のトラブルシューティングとグループ特典

マーカーの設置時や新しい拡張の適用時に、技術的な問題や配置バグが発生することがあります。一般的な問題の解決手順をまとめたクイックリファレンスは以下の通りです。

| 問題 | 根本的な原因 | 解決方法 |
| :--- | :--- | :--- |
| **拠点マーカーを配置できない** | 地形の傾斜が急すぎる、またはマップ境界と重なっている | 建物の当たり判定から離れた平坦な地形へ移動する |
| **アップグレードが保存されない** | サーバーのアクティブセーブ中に切断された | 終了する前に一度地上へ戻り、通常のリスポーンセーブを発生させる |
| **ペットが現金を生成しなくなった** | 金庫の保管容量が上限に達している | すぐに現金を回収するか、金庫保管容量のティアを上げる |
| **グループ報酬が受け取れない** | ゲーム内スクリプトでグループメンバーシップが認識されていない | Robloxで「Sutik x Tommy」グループに参加し、ゲームに再参加する |

## よくある質問（FAQ）

### 最初に購入すべきおすすめの拠点アップグレードは何ですか？
最初に優先すべきは「ペット配置スロット（Pet Placement Slots）」と「基本金庫容量（Basic Vault Storage）」です。スロットを拡張すると同時に多くのペットを装備できるようになり、序盤のパッシブ収入が一気に跳ね上がります。地上を探索している間に金庫が満杯になるようになったら、溢れた収益を捨てないために金庫上限を引き上げましょう。

### 拠点のアップグレードやペットを盗難から守るにはどうすればいいですか？
入り口マーカー用の「視覚迷彩（Visual Camouflage）」を購入し、「防犯ワイヤートラップアラーム（Security Tripwire Alarm）」を設置することで拠点を守ることができます。さらに、ポータルを崖の張り出しの下、密集した茂みの中、障害物の裏など、人目につかない場所に隠して配置すると発見されにくくなります。

### サーバーから退出すると拠点のアップグレードはリセットされますか？
いいえ、拠点の設備アップグレード、解放したペットスロット、購入した防衛トラップはすべてRobloxアカウントのセーブデータに保存されます。新しいサーバーに入り直しても、拠点のステータスや購入済みティアは自動的に引き継がれます。

### 他のプレイヤーに拠点のアップグレード自体を盗まれることはありますか？
いいえ、追加スロット、金庫拡張、セキュリティトラップなど、一度購入したインフラ系のアップグレードそのものを相手に盗まれることはありません。レイダーが盗めるのは、秘密の入り口を見つけられて拠点内に侵入された場合に、無防備に置かれているペットのみです。
