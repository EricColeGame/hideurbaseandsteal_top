## 基本メカニクスと序盤の進め方

高度な強奪を実行する前に、基本的なゲームプレイのサイクルを理解しておく必要があります。目立たない地形の選定からポータルの設置に至るまで、すべての行動が「ライバルからどれだけ資産を奪われやすいか」に直結します。

```
秘密のマーカーを設置 -> 隠しベースに進入 -> ペットを配置して資金稼ぎ -> ライバルのポータルを捜索 -> ペットを強奪して脱出
```

### ゲームプレイサイクルの詳細

1. **マーカーの設置**: オーバーワールドマップにスポーンすると、設置用のマーカーを所持しています。このポータルを地形上に置くことで、あなた専用のベースへの入口が作成されます。
2. **インナータイクーンの発展**: 自身のポータルを踏むと、インスタンス化された地下空間（Vault）へテレポートします。ここでは、初期資金を使ってパッシブ収入を生み出すペットを購入・配置します。
3. **マップの偵察**: ベースが安定して収入を生み出し始めたら、オーバーワールドに戻り、木々の陰や岩の後ろ、マップの隅などに隠された敵のポータルマーカーを探します。
4. **強奪の実行**: 相手のマーカーをインタラクトすると、そのプレイヤーのベースへ直接テレポートします。相手の防備が手薄であれば、高価値なペットを奪い取って自分のベースへと持ち帰ることができます。

| :--- | :--- | :--- | :--- |
| **マーカーの設置** | 人通りの多い中央エリアを避けて入口を隠す | 極めて高い | 地形の影、隅、生い茂った草木を活用する |

## 強奪（Heist）を極める：潜入とペット強奪のテクニック

盗みはこのゲームの面白さの半分を占めていますが、効率的に実行するには素早い行動と状況判断が不可欠です。この**Hide ur Base and Steal 攻略ガイド**を活用して、他人の縄張りに足を踏み入れた際に現行犯で捕まらない立ち回りを身につけましょう。

### 強奪の手順とプレイブック

1. **周囲のスキャン**: マーカーのかすかな光や、プレイヤーが突然消えた瞬間を見逃さないようにしましょう。プレイヤーのアバターが空中でふっと消えた場合、その足元に隠されたマーカーが存在します。
2. **待ち伏せの確認**: 経験の浅い泥棒は、ポータルを見つけると何も考えずに飛び込んでしまいます。まずは周囲を見渡し、ベースの持ち主がマーカーを見張っていないか、あるいは内部で待ち伏せしていないかを確認しましょう。
3. **高価値ターゲットの選定**: 敵のベースに入ったら、素早くペットのコレクションを確認します。初期レベルの低ランクペットを盗んで時間を無駄にしてはいけません。キャッシュ倍率が最も高いレアペットを最優先で狙いましょう。
4. **安全な脱出の確保**: ペットを抱えたら、即座に出口ポータルへと向かいます。持ち主はいつベースに戻ってくるかわからないため、スピードが何よりも命です。


## よくある質問（FAQ）

### この Hide ur Base and Steal 攻略ガイドで最初に優先すべきことは何ですか？
高ランクのペットに多額の資金を費やす前に、まずは見つかりにくく到達しづらいマーカーの設置場所を確保することを最優先してください。ポータルマーカーが序盤で見つかってしまうと、他のプレイヤーに何度も侵入され、軌道に乗る前に資産を根こそぎ奪われてしまいます。

### オフライン中に他のプレイヤーにペットを盗まれることはありますか？
いいえ。『Hide ur Base and Steal』では、ベースとその中身はアクティブなサーバーセッションに紐づいています。ゲームからログアウト（切断）すると、あなたのポータルマーカーとベースはオーバーワールドマップから完全に消去されます。

### マーカーの場所が誰かに見つかった場合、どうやって移動すればいいですか？
設置コントロールを開くことで、ポータルマーカーを回収して再設置できます。現在のポータル周辺が見張られていると感じたら、即座に回収し、外周などの人気のない隔離された場所へ移動して新しく設置し直しましょう。

### Hide ur Base and Steal の最新コードはどこで確認できますか？
新しいコードは通常、開発者の公式Robloxグループ「Sutik x Tommy」内や、ゲームのアップデート告知時に公開されます。コミュニティの告知ボードをチェックするか、最新情報が随時更新される本ガイドを再度ご確認ください。
