## コアメカニクスの理解：ポータル、ペット、レイド

『Hide ur Base and Steal』のゲームプレイループは、古典的なタイクーン要素と緊迫感あふれるステルス＆索敵要素が融合しています。各プレイヤーは共有マップ上に進入用ポータルを設置します。ポータルをくぐると個別の地下サンクチュアリへ転送され、そこでペットを購入して受動的な収益を生み出し、貴重なお宝を保管します。

しかし、あなたのサンクチュアリの安全性は、地上にあるポータルマーカーの隠し方次第です。オーバーワールド（地上マップ）で対戦相手にマーカーを見つけられると、相手は直接内部に飛び込み、防衛する暇もなく苦労して手に入れたペットを奪い去ってしまいます。レイドは攻守のバランスが鍵となります。自身の拠点を感知されない状態に保ちながら、フィールドを索敵してライバルの入り口を見つけ出さなければなりません。

| ゲーム要素 | 主要な役割 | 戦術的な優先度 |
| :--- | :--- | :--- |
| **進入マーカー** | プレイヤーを基地内部へテレポート | 高：人通りの少ない場所や視界が遮られたエリアに隠す |
| **ペット** | 時間経過で自動的にキャッシュを生成 | 最重要：アップグレードし、侵入者から厳重に守る |

## ポータルを安全に守るオーバーワールドの隠し場所

長時間のプレイセッションを生き残るための基盤は、入り口の配置場所にあります。初心者のプレイヤーはメインのスポーン地点付近や広い通路の真ん中にポータルを置きがちで、徘徊する偵察者の格好の標的になります。収益を確実に守るためには、複雑な地形、高低差のある足場、そして周囲に溶け込むテクスチャを活用しましょう。

### 高度なポータル偽装戦術

1. **ジオメトリの隙間や岩の裂け目：** 狭い岩の裂け目や、カメラアングルによって射線が遮られる自然のオブジェクトの背面にポータルマーカーを押し込みます。
2. **高い足場・高所：** 一般的な侵入者の多くは、ダッシュ中に正面を見るか下を向いて走っています。高い崖の出っ張りや木の天蓋にマーカーを配置すると、敵は上を見上げたり、パルクールジャンプを駆使しないと到達できなくなります。
3. **生い茂る草木のカムフラージュ：** 密集した茂みや重なり合う葉を探しましょう。装飾用植物の内側にマーカーを配置することで、遠くのプレイヤーから見える発光パーティクルエフェクトを隠すことができます。

| スポットタイプ | 到達難易度 | 侵入者からの視認性 | 危険度 |
| :--- | :--- | :--- | :--- |
| **開けたスポーン広場** | 極めて低い | 最大 | 非常に危険 |
| **隅の茂み・草木** | 低い | 低〜中 | 中程度 |
| **高所の崖・足場** | 高い | 低い | 低い |
| **地形の深い裂け目** | 中 | 極めて低い | 極めて低い |
| **マップ外周の裏側** | 高い | 最小限 | 安全 |

入り口を設置したら、カメラをズームアウトして360度回転させてみてください。もしベースマーカーが周囲の地形から浮いて見える場合は、ペットを配置する前に一度回収し、別の場所へ移設しましょう。

## 攻撃的なレイド：ライバルのペットを追跡して奪う方法

隠されたポータルを見つけるには、忍耐力、鋭い観察眼、そしてプレイヤー心理の理解が必要です。多くのプレイヤーは外周の壁沿いに隠すか、高ティアのリソーススポーン地点の近くに集まる傾向があります。

強奪を成功させるには、わずかな光の歪みや足音に注意を払ってください。多くのプレイヤーは、オープンワールドでキャッシュを集めた後、自分のアジトに向かって真っ直ぐ走るため居場所が露呈します。安全な距離を保って尾行し、相手がポータルに飛び込んだ直後を見計らって背後からすり抜けましょう。

| レイドフェーズ | 侵入者のアクション | 推奨ツール / 行動 |
| :--- | :--- | :--- |
| **偵察** | マップ外周や高所地形のパトロール | カメラをズームアウトしたまま維持し、プレイヤーの動きを監視 |
| **潜入** | 気づかれずにターゲットのマーカーへ進入 | 足音を抑えるためにしゃがみ/ステルス歩きを活用 |
| **選定** | 部屋の中で最も高ランクのペットを特定 | レアリティ表示と基礎収益倍率をすばやくスキャン |

多くのプレイヤーの経験上、何よりもスピードを最優先すべきです。超レアなペットをどれにするか迷って戻ってきた拠点オーナーに捕まるくらいなら、中堅ティアのペットを掴んですぐに逃げ去る方がはるかに賢明です。

## よくある質問

### ソロプレイヤーに最適なhide ur base and steal secrets（拠点の隠し方）は何ですか？
ソロに最適な戦略は、拠点の存在感を最小限に抑えることです。見つかりにくい高所の地形にマーカーを設置し、高収益のペットを購入して、貯まった銀行残高を定期的に回収しましょう。インベントリを身軽にしておけば、万が一拠点が発見されても侵入者が得られる利益はほとんどありません。

### オフライン中に対戦相手からペットを盗まれることはありますか？
いいえ。切断すると、あなたの基地とポータルマーカーはアクティブなサーバーからアンロードされます。ペットはプロフィールのインベントリ内に安全に保持され、再びゲームセッションに参加してマーカーを設置するまで盗まれることはありません。

### 敵のポータルにプレイヤーがいるかどうかを見分けるにはどうすればよいですか？
拠点のポータル付近に表示されるアクティブな収益数値を確認するか、マーカーの境界内部から聞こえる足音に耳を澄ませてください。また、オーバーワールドのプレイヤーリストを確認するのも有効です。フィールド上に見当たらないプレイヤーは、基地の内部でペットの編成を行っている可能性が高いです。

### Hide ur Base and Stealでコードが使えないのはなぜですか？
コードは大文字と小文字が区別され、余分なスペースを入れずに開発者が指定したとおりに入力する必要があります。コードが通らない場合は、有効期限が切れているか、すでにそのアカウントで引き換え済みの可能性があります。新しいコードをいち早く入手したい場合は、公式のSutik x Tommy Robloxコミュニティグループに参加するのが最も確実です。
