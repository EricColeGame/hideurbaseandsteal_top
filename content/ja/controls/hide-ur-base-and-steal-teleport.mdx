## 完全操作ガイド：移動、インタラクト、テレポート

ライバルを奇襲したり、自身の収入源を守るためには、まず基本操作を完全に使いこなす必要があります。PC、モバイル、コンソールコントローラーのいずれでプレイする場合でも、滑らかな移動操作が現場で捕まらないための基本となります。

テレポートマーカーはホットバー内のインタラクティブアイテムとして扱われます。これを設置することで、パブリックなオーバーワールドとプライベートな地下タイクーン拠点を繋ぐエントランスパッドが出現します。他のプレイヤーのマーカーを操作するとその金庫内へ高速ワープできるため、追走劇の最中には正確なタップやクリックが命運を分けます。

| アクション / 機能 | PC (キーボード & マウス) | モバイル (タッチ操作) | コンソール (Xbox / PS) |
| :--- | :--- | :--- | :--- |
| **キャラクター移動** | `W, A, S, D` | 左仮想ジョイスティック | 左スティック |
| **カメラ操作** | マウス移動 / 右クリックドラッグ | 画面右側ドラッグ | 右スティック |
| **ジャンプ / 乗り越え** | `スペースキー` | ジャンプボタン（画面右下） | `A` (Xbox) / `×` (PS) |
| **テレポートマーカー装備** | `1` - `9` ホットバーキー | スロット内のアイテムアイコンをタップ | `方向キー` 左 / 右 |
| **テレポート設置** | マウス左クリック | 画面の対象エリアをタップ | 右トリガー (`RT` / `R2`) |
| **インタラクト / ペット強奪** | `E` キー（長押し） | インタラクトプロンプトをタップ | `X` (Xbox) / `□` (PS) |
| **ショップ / コードを開く**| UIアイコンをクリック | メニューボタンをタップ | ビュー / タッチパッドボタン |

### レイドに役立つ高度な操作テクニック
* **カメラの視点調整**: 険しい地形をダッシュする際は、カメラをわずかに下向きに傾けておきましょう。この角度に保つことで、草、土、水のエフェクトに紛れたわずかな発光テレポートマーカーを発見しやすくなります。
* **ダッシュの維持**: 常に前進する勢いを維持してください。敵の入り口に突入する際に立ち止まったり足踏みしたりするとインタラクトの遅延が発生し、ペットを奪う前に拠点オーナーへ通知が届いてしまいます。
* **緊急脱出ルートの把握**: 相手のシェルターに飛び込んだ瞬間、必ず内部の脱出用ワープパッドの位置と向きを記憶し、強奪完了と同時に即座に逃走できるようにしましょう。

## Hide ur Base and Steal のテレポート仕様と仕組み

ゲームプレイの核心は、ダイナミックに設置できるリフトゲートウェイにあります。サーバーに参加すると、プレイヤーは設置可能なスポーンリフトを所持しています。このアイテムを使用すると、オーバーワールドの地形上にポータルマーカーが配置されます。

展開したマーカーの上に直接乗ることで、**hide ur base and steal teleport**シーケンスが発動し、アバターが個人の地下タイクーン内部へと瞬時に移動します。バンカー内では、パッシブ収入を生み出すペットを配置したり、獲得した資金でタイクーンをアップグレードしたり、防衛用バッファーを購入したりできます。

ただし、入り口となるマーカーはパブリックロビーに実体として残り続けます。通りすがりのプレイヤーがその入り口を見つければ、全く同じ**hide ur base and steal teleport**のワープを起動できてしまいます。侵入者が一度プライベート拠点に入り込むと、急いで戻って阻止しない限り、高価なペットを奪われてしまいます。

| テレポート状態 | 視覚 / 音響インジケーター | 使用可能プレイヤー | 主なリスク要因 |
| :--- | :--- | :--- | :--- |
| **未設置** | プレイヤーのホットバーに保持 | 拠点オーナーのみ | 未設置の間は拠点の資金生成がゼロ |
| **隠された入り口** | かすかな発光デカール / オーラ | 踏んだプレイヤー全員 | 偵察中の略奪者に見つかると高リスク |
| **侵入発生中** | パーティクルのきらめき効果 | オーナーおよび侵入中の略奪者 | ペットがリアルタイムで盗まれている最中 |
| **内部脱出パッド** | バンカー内の固定リターンプレート | バンカー内にいる全員 | 泥棒が外の世界へ逃亡可能 |

## テレポートマーカーを隠す最強の拠点スポット

マーカーを発見したプレイヤーは誰でも金庫内に侵入できるため、マップへの理解が極めて重要です。一般的な道路の近くや開けた場所にポータルを置くのは、「どうぞ盗んでください」と言っているようなものです。プレイヤーコミュニティの経験則から言えば、地形の隙間や自然の遮蔽物、高低差を活かした死角を見つけるのが最も効果的です。

敵のスカウトにとって、探すのが最も面倒で直感に反する場所を選ぶのがポイントです。以下に、敵の目からポータルを隠すための地形ランクをまとめました。

| 隠蔽ランク | 場所のタイプ | 視認性 | 敵の通行頻度 | 戦略的メリット |
| :--- | :--- | :--- | :--- | :--- |
| **Sティア (最強)** | 生い茂る茂みの下・深い低木 | 極めて低い | 低 | 低木のテクスチャ内にマーカーのパーティクルを完全隠蔽。 |
| **Aティア (優秀)** | 高所の崖の割れ目・突起部 | 低い | 極めて低い | 高度なパルクールが必要なため、一般的なプレイヤーを排除可能。 |
| **Bティア (良好)** | 浅瀬の水中・アシの茂み | 中〜低 | 普通 | 水面の揺らぎと屈折により、発光エフェクトが目立たなくなる。 |
| **Cティア (普通)** | 中立建造物の裏側 | 中 | 高 | 射線は遮れるが、熟練の泥棒には予測されやすい。 |
| **Fティア (最悪)** | 開けた通路・初期スポーン周辺| 最大 | 極めて高い | 設置から30秒以内にほぼ確実に侵入される。 |

### 戦略的な拠点設置手順
1. **設置前にまず偵察**: スポーンした瞬間にリフトを置くのはやめましょう。まずは初心者がめったに来ないマップの端を目指して走ります。
2. **オブジェクトと同化させる**: 暗い地面、密集した生け垣、倒れた景観オブジェクトを探します。密度の高い葉のモデルの下にマーカーを置くことで、リフトの外枠の輪郭を隠せます。
3. **死角のダブルチェック**: 15スタッドほど後ろに下がり、カメラを360度回転させてみてください。主要なルートからマーカーがはっきりと見える場合は、回収して別の場所に再配置しましょう。

## 攻勢レイド：ポータルの発見とペット強奪

『Hide ur Base and Steal』において、攻撃（レイド）は効率的に進行するための生命線です。自分の拠点でペットがパッシブに現金を稼いでいる間、プレイヤーはライバルの入り口を積極的に探し回るべきです。敵の**hide ur base and steal teleport**ドアを見つけて侵入する方法を知っていれば、本来なら何時間も周回して購入するような高ティアのペットを一瞬で手に入れることができます。

```
       [オーバーワールドの探索]
               │
               ▼
   [隠されたテレポートを発見] ──(パッドを踏む)──► [ライバルの拠点へ侵入]
                                                        │
                                                        ▼
[オーバーワールドへ無事帰還] ◄──(拠点を脱出)─── [高ティアペットを強奪]
```

### レイド時のペット優先順位
敵の拠点に侵入した際、残された時間はごくわずかです。オーナーは収入の減少に気づくか、侵入アラートを受け取った瞬間にワープして戻ってきます。以下の優先度表に従い、最も価値の高い資産から狙いましょう。

| ペットカテゴリー / レア度 | 推定収入レート | 強奪優先度 | 取得所要時間 |
| :--- | :--- | :--- | :--- |
| **ミシック / イベントペット** | 高 ($500+ / 秒) | **最優先 (真っ先に確保)** | 約2.0秒 |
| **レジェンダリーペット** | 中 ($150 - $499 / 秒) | 高 | 約1.5秒 |
| **レアペット** | 控えめ ($50 - $149 / 秒) | 中 (進路にあれば回収) | 約1.0秒 |

## 防衛戦術：侵入者から拠点を守り抜く

ポータルを隠すことだけに依存するのは非常に危険な賭けです。上級スカウトは、草むらやマップの境界線をシステマチックに探索して隠しポータルを探し出します。アジトを安全に保つには、多層的な防衛習慣を身につける必要があります。

コミュニティの報告によると、個人タイマーを設定しておくことで不意の被害を防ぐのに役立ちます。拠点の確認を怠って探索に夢中になりすぎると、侵入者にペットを根こそぎ奪われる原因になります。

| 防衛戦略 | 労力 | 防衛効果 | 実行方法 |
| :--- | :--- | :--- | :--- |
| **定期的なポータル移設** | 普通 | 高 | 8〜10分ごとに入り口マーカーを回収し、別の場所に再設置する。 |
| **おとりルートの移動** | 低 | 普通 | 他のプレイヤーに追尾されている時は、絶対に隠しパッドへ直行しない。 |
| **即時リコール確認** | 高 | 最大 | 高価なペットを購入した直後は、テレポートで即座に帰宅して安全を確認する。 |
| **収入変動の監視**| 低 | 高 | 画面のパッシブ収入を常に注視し、急激な減少があれば盗難発生と判断する。 |

## テレポートと操作のよくある不具合と解決策

目まぐるしく変化するRobloxの物理エンジンでは、時折コリジョン抜け、同期ズレ（ラグ）、プロンプトの無反応などが発生します。重要な脱出時に**hide ur base and steal teleport**がうまく機能しない場合は、以下の対処法を試してください。

| 発生した問題 | 考えられる原因 | 確認済みの対処法 / 回避策 |
| :--- | :--- | :--- |
| **パッドを踏んでも反応しない** | 物理同期ズレ / Pingの上昇 | パッドの中心の真上で繰り返しジャンプする。 |
| **マーカーを設置できない** | 不正な傾斜 / 障害物の干渉 | 壁のヒットボックスから離れ、より平坦な地面に移動する。 |
| **無限ワープ画面で停止する** | サーバー遷移の遅延 | Robloxのメインメニューからキャラクターをリセット（`Esc` + `R` + `Enter`）。 |
| **敵ペットの「E」プロンプトが出ない** | 盗難中にオーナーがペットを回収した | 一度離れてペットの判定枠を再度捉えるか、捕まる前に撤退する。 |
| **奈落（マップ外）にテレポートを設置した**| 落下中にアイテムを使用してドロップした | ホットバーの設置ツールを再度装備し、マーカーを強制回収する。 |

慎重な拠点配置、鋭いカメラ索敵、そして素早い帰還の習慣を組み合わせることで、**hide ur base and steal teleport**のゲームプレイを完全に支配することができます。入り口パッドを巧みに隠し、アグレッシブにレイドを仕掛け、ライバルが防衛破りに気づく前にすべてのペットを手中に収めましょう。

## よくある質問 (FAQ)

### hide ur base and steal teleportマーカーの使い方は？
ホットバーからテレポートマーカーツールを装備し、設置可能な地面を狙ってクリックまたはタップします。パッドが出現したら、キャラクターでその上を歩くだけで、個人の地下金庫内へ直接テレポートできます。

### 他のプレイヤーも自分のテレポートマーカーを使って拠点に入れますか？
はい。他のプレイヤーがオーバーワールド上であなたの隠しマーカーを見つけた場合、そのパッドを踏むことであなたの拠点に瞬時に侵入し、ペットを盗むことができます。ペットを守るためには、茂みや崖、水中などにポータルを隠すことが極めて重要です。

### 拠点の場所がバレてしまったらどうすればいいですか？
敵にマーカーを発見された場合は、急いで自分の拠点に入ってペットの安全を確保し、オーバーワールドに戻ります。その後、テレポートパッドを回収し、マップのまったく異なるエリアへ移動して、新しい隠し場所に再設置してください。

### 拠点をアップグレードすると泥棒に盗まれにくくなりますか？
タイクーン拠点をアップグレードすると、敷地が拡張され、より高い収入を生むペットスロットが解放されますが、入り口を見つけたプレイヤーに対するテレポート自体のアクセス性は変わりません。最大の防御策は常に「隠蔽」「頻繁な場所移動」「周囲への警戒」を怠らないことです。
