## 基本システムと盗みのアクション操作

潜入を開始する前に、基本的な移動操作とインタラクトキーをマスターしておく必要があります。盗んだペットを運んでいる間は機動力が大幅に低下するため、防衛に戻ってきた拠点オーナーに追い詰められないよう、精密なキー入力が必須となります。

| アクション / 機能 | PCキー設定 | モバイル / タブレット操作 | コンソール（Xbox/PlayStation） |
| :--- | :--- | :--- | :--- |
| **移動** | W, A, S, D | バーチャルジョイスティック | 左アナログスティック |
| **調べる / 盗む** | Eキー（長押し） | 画面上の「Steal」ポップアップ | Xボタン / □ボタン |
| **拠点マーカー設置** | 左クリック（アイテム装備時） | 画面上のボタンをタップ | 右トリガー（RT / R2） |
| **ダッシュ / スプリント** | 左Shift | スプリントアイコンをタップ | 左スティック押し込み（L3） |
| **ショップを開く** | UIクリック（ショップタブ） | カートボタンをタップ | Select / タッチパッドメニュー |

強盗を試みる際は、カメラの向きが周囲への警戒度を左右します。背後からオーナーがテレポートしてくるのに対処できるよう、視点は常に拠点のポータル側へ向けておきましょう。プレイヤーの経験上、視野（FOV）を少し広めにズームアウトしておくと、ペットの回収作業中に待ち伏せ攻撃を受けるリスクを劇的に低減できます。

## Hide Ur Base and Steal How to Steal：潜入の完全フロー

鮮やかに強盗を成功させるには、体系的なアプローチが必要です。ただマップ上を当てもなく走り回っても、熟練したビルダーなら隠し入り口を見つけられる前に侵入者を察知してしまいます。**hide ur base and steal how to steal**を実践するには、「偵察」「突破」「確保」「安全な脱出」という4段階のサイクルを把握することが重要です。

```
[フェーズ1: 偵察] ➔ [フェーズ2: 突破と安全確認] ➔ [フェーズ3: ペット選定] ➔ [フェーズ4: 脱出]
```

### フェーズ1: 隠された拠点マーカーの特定

すべてのプレイヤーは、自身の地下バンカーへアクセスするためにテレポートマーカーをワールド内に配置する必要があります。油断しているビルダーは、スポーン地点の近く、木立の陰、初期ショップの裏などにマーカーを置きがちです。

1. **死角をチェック:** 地形の大岩の裏側、スロープ下の暗い角、密集した茂みの中を入念に探しましょう。
2. **プレイヤーの動きを観察:** 人通りの多いエリアからダッシュしていき、突然姿を消すプレイヤーを見逃さないようにしてください。消えた場所こそがポータルマーカーの位置です。
3. **音の合図:** 地下室へ出入りする際には独特のテレポート効果音が鳴るため、耳を澄ませば方角を絞り込めます。

### フェーズ2: ポータルからの突破

敵のマーカーを踏むと、即座に相手のプライベートタイクーン内部へとテレポートします。到着した瞬間は完全に息を潜め、仕切り壁の陰でしゃがむか立ち止まってください。不用意に前へダッシュすると、足音でインベントリを整理中のオーナーに気づかれてしまいます。

### フェーズ3: ペットの選定と確保速度

すべてのペットが同じ価値を持っているわけではありません。**hide ur base and steal how to steal**のノウハウを適用してインベントリ効率を最大化するには、初期ペットよりも倍率の高い上位クリーチャーを常に優先して狙いましょう。

| ペットのレア度 / タイプ | 基本キャッシュ倍率 | 確保に必要な長押し時間 | 移動速度への影響 |
| :--- | :--- | :--- | :--- |
| **Common（初期）** | 1倍 - 3倍 | 1.0秒 | ほぼなし（通常速度） |
| **Rare / Utility** | 5倍 - 10倍 | 1.8秒 | 移動速度 -5% |
| **Epic / Mythic** | 15倍 - 30倍 | 2.5秒 | 移動速度 -15% |
| **Secret / Event** | 50倍以上 | 3.5秒 | 移動速度 -25% |

円形の盗みメーターがいっぱいになるまでインタラクトキーを押し続けます。途中で動いたりダメージを受けたりしてメーターが中断された場合、長押しは最初からやり直しになります。

### フェーズ4: 脱出と自拠点への移送

ペットを手にしたら、ポータルへと全速力で駆け戻り、直ちに自分の拠点マーカーを目指します。盗み出しただけではペットは保管庫に追加されず、自分の拠点の境界線を越えて空いている展示ポッドに配置して初めて正式に自分のものとなります。

## 必須の装備と移動戦略

激しいレイドを生き残るには入念な準備が欠かせません。移動速度を底上げする手段を持たずに潜入すると、防衛側にあっという間に追いつかれてしまいます。**hide ur base and steal how to steal**を実行する際は、以下の立ち回りテクニックを常に意識してください。

* **コーナーピーク:** メインのペット展示スペースへ足を踏み入れる前に、三人称視点カメラを回して通路の曲がり角の先を確認します。
* **防衛の釣り出し:** 敵が出入り口を厳重に警戒している場合、一度退却するフリをして開けた場所へ誘い出し、高低差を利用した別ルートから回り込みます。
* **インベントリの空き管理:** ライバルのマーカーを踏む前に、両手を空にしておきましょう。不要なユーティリティアイテムを持っていると、高価値なペットに手を伸ばす際にインタラクトの入力が遅れる原因になります。

## 拠点の隠し方：ライバルの泥棒から保管庫を守る

攻めを極めるのは戦いの半分にすぎません。自分のポータルマーカーが簡単に見つかる場所にあれば、他人の拠点を襲撃している最中に自分の保管庫が空にされてしまいます。生き残るためには、人目につかない優れたマーカーの隠し場所を構築することが極めて重要です。

| 拠点の隠し場所 | カモフラージュ評価 | アクセスの容易さ | 総合セキュリティ評価 |
| :--- | :--- | :--- | :--- |
| **マップ上の橋の下** | 中（3/5） | 高（出入りしやすい） | 普通 |
| **深い樹木の茂み** | 高（4/5） | 中（葉で視線が遮られる） | 非常に良い |
| **外周の崖・高所** | 極めて高（5/5） | 低（パルクール技術が必要） | 最上級 |
| **初期エリアの平地** | 低（1/5） | 高（素早く移動可能） | 脆弱 |

### 多重内部防衛の構築

外側のマーカーを隠すだけでなく、内部レイアウトを工夫して侵入者の貴重な時間を奪いましょう。

* **迷路構造の通路:** 基本の壁材を使って曲がりくねった通路を作り、侵入者が歩く距離を強制的に増やします。
* **高ランクペットの奥地配置:** 最も高価なペットは入り口付近を避け、バンカーの最奥部に配置してください。
* **おとりの展示:** 低ランクのペットを入り口付近に並べておくことで、手っ取り早く済ませたい泥棒にそれを掴ませ、深くまで探索させずに退散させることができます。

## レイド戦略の比較：単独潜入 vs チーム強盗

公開ロビーにおいて、1人で潜入するかフレンドと連携して挑むかで強盗の効率は大きく変わります。これらの戦略的な違いを理解することで、**hide ur base and steal how to steal**の精度を一段と高めることができます。

| 戦略の特徴 | ソロ潜入 | デュオ / トリオチームレイド |
| :--- | :--- | :--- |
| **発見リスク** | 最小限（単独のため目立たない） | 中程度（視覚的な存在感が大きい） |
| **回収能力** | 1回につき高ランクペット1体 | 同時に2〜3体を確保可能 |
| **番兵の陽動** | 不可（即座に逃走する必要あり） | 高い（味方がオーナーをおびき寄せる） |
| **準備時間** | 早い（マーカーを置いて即狩り） | 遅い（マーカー位置の連携が必要） |
| **おすすめのターゲット** | 留守 / 放置（AFK）中のバンカー | 厳重に要塞化された保管庫 |

コミュニティの報告によると、1人のプレイヤーが入り口付近で意図的に足音を立ててオーナーを引きつけ、もう1人が後方の列からレアなクリーチャーを素早く回収する連携を行うことで、脱出成功率が約60%向上することが分かっています。

## 盗みに失敗する場合の高度なトラブルシューティング

窃盗が途中で失敗してしまうことが多い場合、以下のゲームシステム上の要因が原因となっている可能性があります。

1. **長押しの解除が早すぎる:** ゲージが満タンになる数ミリ秒前にインタラクトボタンを離すと、強盗は即座にキャンセルされます。キャラクターモデルがペットを完全に担ぎ上げるまでキーを離さないでください。
2. **Pingのスパイク（高遅延）:** サーバーの遅延が大きいと、画面表示とサーバー処理の間で同期ズレが生じます。入力がうまく認識されない場合は、より応答速度の良いサーバーへ切り替えてみてください。
3. **オーナーのテレポート遮断・移動:** 侵入中に拠点のオーナーがログアウトしたり、外の拠点マーカーを移動させたりすると、バンカーが強制閉鎖され、戦利品を持たない状態でマップ中央へ戻されてしまいます。

## よくある質問（FAQ）

### 自分が相手の拠点を襲っている最中に、他のプレイヤーに自分のペットを盗まれることはありますか？
はい。襲撃はリアルタイムで同時に進行します。別の拠点をレイドしている間に敵があなたのマーカーを発見した場合、マーカーをうまく隠していなければ相手は簡単にあなたの保管庫へ侵入し、ペットを盗み出すことができます。

### 盗んだペットを運んでいる最中に倒されたらどうなりますか？
自分の拠点に入る前にキャラクターがリセットされたり、トラップや敵プレイヤーによって倒されたりした場合、抱えていたクリーチャーはその場にドロップし、元のオーナーの展示台へとリスポーンして戻ります。

### オーナーが拠点の中にいてもペットを盗むことはできますか？
可能ですが、危険度ははるかに高くなります。オーナーが近くにいても盗むためのインタラクト操作自体はロックされません。ただし、相手は直接追いかけてきたり、進路を妨害したり、ポータルに到達する前に攻撃してペットを落とさせようとしてきます。

### ペットに近づいても盗むプロンプトが表示されないのはなぜですか？
コミュニティの報告によると、アバターがツールや消費アイテムを手に持っている場合に発生しやすいとされています。手持ちを空にし、ペットの台座に密着して立ち、さらにオーナーが一時的な拠点保護パークなどで部屋をロックしていないか確認してください。
